# OpsPulse – Project Requirements

## 1. Project Overview

OpsPulse is a responsive Operations Management Dashboard designed to help administrators monitor business operations, customer orders, revenue and important alerts.

## 2. Project Objectives

- Display important business information in one dashboard.
- Monitor customer orders and their statuses.
- Provide visual analytics using charts.
- Search and filter orders.
- Display important operational alerts.
- Provide administrator profile settings.

## 3. Functional Requirements

1. Dashboard must display revenue, orders, customers and pending orders.
2. Dashboard must display revenue and order status charts.
3. Users must be able to view all orders.
4. Users must be able to search orders.
5. Users must be able to filter orders by status.
6. Users must be able to view and dismiss alerts.
7. Administrators must be able to update profile form fields.
8. The settings form must validate user input.
9. The application must handle loading, empty and error states.
10. Navigation must work across all application pages.

## 4. Non-Functional Requirements

- Responsive layout for desktop, tablet and mobile.
- Reusable React components.
- Accessible form labels and keyboard navigation.
- Clear visual feedback for user actions.
- Maintainable and organized project structure.

## 5. Technology Stack

- React.js
- JavaScript
- Vite
- Tailwind CSS
- React Router DOM
- Recharts
- Lucide React
- Mock API and sample data

## 6. Project Scope

This project is a frontend dashboard demonstration using sample data. It does not include a real backend, database or live business transactions.
