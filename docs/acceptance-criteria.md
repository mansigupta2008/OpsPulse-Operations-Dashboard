# OpsPulse – Acceptance Criteria

## 1. Dashboard

- Dashboard loads successfully.
- KPI cards display revenue, orders, customers and pending orders.
- Revenue chart displays monthly revenue data.
- Order status chart displays order distribution.
- Loading, error and empty states are handled.

## 2. Orders Management

- All sample orders are displayed in a table.
- Search works by order ID, customer name and product name.
- Status filter works correctly.
- Matching order count is displayed.
- Empty state appears when no matching orders are found.

## 3. Analytics

- Analytics page opens successfully.
- Revenue and order status charts are visible.
- Revenue, order count and delivery rate are displayed.

## 4. Alerts

- Alerts are displayed with suitable status indicators.
- Users can dismiss individual alerts.
- Empty state appears when all alerts are dismissed.

## 5. Settings

- Profile form displays name, email and role.
- Name validation works.
- Email validation works.
- Role validation works.
- Success message appears after valid submission.

## 6. Navigation

- All sidebar links open the correct pages.
- Active navigation item is highlighted.
- Invalid routes display the 404 page.

## 7. Responsive Design and Accessibility

- Layout adapts to desktop, tablet and mobile screens.
- Form fields have associated labels.
- Interactive elements can be reached using a keyboard.
- Visible focus indicators are provided.

## 8. Overall Acceptance

The project is accepted when all implemented features work correctly, the application runs without errors, and the documented limitations are clear.
