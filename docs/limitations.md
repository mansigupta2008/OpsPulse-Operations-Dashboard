# OpsPulse – Project Limitations

## 1. Mock Data

The dashboard currently uses predefined sample data instead of live business information.

## 2. No Real Backend

The application does not connect to a backend server or database.

## 3. Simulated API

API requests are simulated using JavaScript Promises and a delay. They do not communicate with an external API.

## 4. Profile Settings

Profile information is managed in React state and is not permanently saved.

## 5. Authentication

The project does not currently include administrator login or authentication.

## 6. Notifications

Alerts are sample notifications. They are not received from a live notification service.

## 7. Analytics

Charts display predefined sample analytics and are not connected to live transactions.

## 8. Future Improvements

- Connect a real backend API.
- Add database integration.
- Implement administrator authentication.
- Save profile settings permanently.
- Add real-time notifications.
- Connect analytics to live business data.
- Add automated testing.

## 9. Conclusion

OpsPulse demonstrates frontend dashboard development, reusable React components, data visualization, search, filtering, form validation and responsive interface design. The limitations listed above define the current demonstration scope.
